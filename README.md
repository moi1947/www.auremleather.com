# Aurem - Official Website

Official website for Aurem, representing leading leather manufacturers in Spain.

## Features

- Responsive design for all devices
- Multilingual support (Spanish, English, Polish)
- Contact form functionality
- Interactive elements and smooth scrolling

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Font Awesome Icons
- Google Fonts (Inter)

## Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/aurem-website.git
   cd aurem-website
   ```

2. Open `index.html` in your preferred web browser.

## Deployment

This website is designed to be static and can be hosted on any web server or static hosting service like:
- GitHub Pages
- Netlify
- Vercel
- Any traditional web hosting service
